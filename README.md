# Al-Rizwan Question Paper Software

Desktop software to build Al-Rizwan English School question papers from pasted or uploaded questions:
auto-layout to the school template, grammar check (English, Hindi, Marathi, Urdu), question bank with
history by class, subject and exam.

## Folders

- `specs/` — the build plan and rules (source of truth)
- `ANTIGRAVITY-PROMPT.md` — prompt to start the build in Antigravity
- `assets/` — put the school logo here as `logo.jpg`

Code folders (`app/`, `server/`, `config/`, `data/`) are created during Phase 1.
